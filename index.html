The weeks at a glance

Plan for 6-10 hours each week and one mentor sync. Work in order. If a milestone needs more time, extend the week.

WeekFocusMilestone
1npm and ViteThe calculator loads Scale from npm, runs locally and builds.
2Node.js and package filesA dependency report works; you explain promises, versions and scripts.
3The toolchain and local Scale setupScale runs from source; you explain its install, build and start commands.
4TypeScriptThe calculator passes strict type checks without suppressed errors.
5Web ComponentsA calculator history element works and sends a custom event.
6StencilYou build the history element with Stencil and explain a Scale component.
7Tests and StorybookA regression test goes from failing to passing; you select a small Scale issue with your mentor.
8Your first Scale bug-fix PRA focused fix has a test, a clear PR description and passing CI. You respond to review.

The week 8 target is an open, review-ready PR. The merge date also depends on the maintainers. See the full learning plan for the topics in each week.
