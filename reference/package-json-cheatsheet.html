                 └── package name ─────────┘ └ tag ┘ └── path inside the package ─────────────┘

node_modules/@telekom/scale-components/dist/scale-components/scale-components.esm.js

unpkg serves files from the npm registry. npm install copies the same files into node_modules/. With no path, unpkg serves the file named in the package's "unpkg" field.

Dist-tags

A dist-tag is a name that points to one published version. npm install pkg = pkg@latest. Check with npm view <pkg> dist-tags.
Scale on 2026-10-02: latest → 3.0.0-beta.161, next → 3.0.0-beta.156 (older!).

Lock files

package-lock.json (npm) / yarn.lock (Yarn) record the exact version of every installed package. Commit them. Never commit node_modules/.

Bare specifier

import { defineCustomElements } from '@telekom/scale-components/loader'; // bare: a name, not a URL

The browser alone cannot resolve a bare name (MDN: modules). A dev server or bundler such as Vite finds it in node_modules for you.
