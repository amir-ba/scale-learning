# Starting point: C++/OOP, browser JS, Scale from unpkg

The mentor reports this prior knowledge: C++ and OOP (with interest in design patterns), HTML/JS/CSS basics, git basics, Node.js and Web Components basics. The student built a calculator with HTML + JS, JSDoc type comments, and Scale components loaded from unpkg (no npm, no bundler).

**Evidence**: mentor statement, 2026-10-02. Depth not yet tested.

**Implications**: Do not re-teach classes, objects or basic DOM. The first gap is the toolchain: `package.json`, `node_modules`, npm scripts, and why a bundler exists. JSDoc types are a direct bridge to TypeScript. Test the Web Components basics (Shadow DOM, slots, attributes vs. properties) before Stencil lessons.
